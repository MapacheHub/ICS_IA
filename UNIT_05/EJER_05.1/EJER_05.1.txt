En esta práctica construyes una pequeña «Guía del centro» con Next.js y comprendes cómo se organizan las carpetas, cómo se comparte un layout, cómo se crean rutas y qué diferencia hay entre un componente de servidor y uno de cliente. 

## Qué vas a construir

Una aplicación con tres páginas que comparten cabecera y pie. En la página de aulas, cada aula es una tarjeta con un botón para marcarla como favorita.

| Dirección | Archivo | Qué muestra |
| --- | --- | --- |
| `/` | `app/page.tsx` | Bienvenida |
| `/sobre` | `app/sobre/page.tsx` | Información sobre la guía |
| `/aulas` | `app/aulas/page.tsx` | Tres tarjetas de aulas |

Al terminar, la carpeta `app/` tendrá esta estructura:

```
app/
├── layout.tsx
├── page.tsx
├── globals.css
├── sobre/
│   └── page.tsx
├── aulas/
│   └── page.tsx
└── componentes/
    ├── TarjetaAula.tsx
    └── BotonFavorita.tsx
```

Trabaja con la terminal y el editor abiertos. Cada parte termina con una comprobación: no pases a la siguiente si no funciona.

## Parte 3 · El layout compartido

El `layout.tsx` envuelve a todas las páginas: lo que pongas aquí aparece en todas las rutas. Cada página llega a través de `children`.

1. Abre `app/layout.tsx` y localiza `children`.
2. Sustituye su contenido por el siguiente. Fuera del código, tres cosas nuevas:
    - `import type { Metadata }` importa solo un tipo de TypeScript. `metadata` define el título de la pestaña: Next.js lo lee por su nombre exacto.
    - `Link` es el componente de Next.js para enlazar páginas sin recargar el navegador. Funciona como un `<a href>`.
    - `LayoutProps` es un tipo que Next.js genera: no se importa.

```tsx
import type { Metadata } from "next";
import Link from "next/link";
import "./globals.css";

export const metadata: Metadata = {
  title: "Guía del centro",
  description: "Aulas y servicios del centro",
};

export default function RootLayout({ children }: LayoutProps<"/">) {
  return (
    <html lang="es">
      <body className="flex min-h-screen flex-col bg-zinc-50 text-zinc-900">
        <header className="bg-zinc-900 px-6 py-4 text-white">
          <nav aria-label="Principal" className="flex gap-6">
            <Link href="/">Inicio</Link>
            <Link href="/aulas">Aulas</Link>
            <Link href="/sobre">Sobre la guía</Link>
          </nav>
        </header>
        <main className="mx-auto w-full max-w-3xl flex-1 px-6 py-8">
          {children}
        </main>
        <footer className="px-6 py-4 text-center text-sm text-zinc-500">
          Guía del centro · Práctica de iniciación a Next.js
        </footer>
      </body>
    </html>
  );
}
```

1. Navega con los enlaces de la cabecera por las tres páginas. La cabecera y el pie se mantienen; solo cambia el contenido de `main`.
2. Responde la pregunta 1 de la hoja de respuestas.

**Comprueba:** la pestaña del navegador se llama «Guía del centro» y la cabecera aparece en las tres páginas.

## Parte 4 · Componentes de servidor y de cliente

Por defecto, todo componente de Next.js se ejecuta en el servidor. Solo los que necesitan estado, eventos o el navegador deben ser de cliente. Vas a crear uno de cada tipo.

1. Crea la carpeta `app/componentes`. Dentro crea `BotonFavorita.tsx`. **Escríbelo tal cual, sin nada más en la primera línea**:

```tsx
import { useState } from "react";

export default function BotonFavorita() {
  const [esFavorita, setEsFavorita] = useState(false);

  return (
    <button
      type="button"
      aria-pressed={esFavorita}
      onClick={() => setEsFavorita((anterior) => !anterior)}
      className="mt-3 rounded bg-zinc-900 px-3 py-1 text-white"
    >
      {esFavorita ? "★ Favorita" : "☆ Marcar como favorita"}
    </button>
  );
}
```

1. Crea `TarjetaAula.tsx` en la misma carpeta. Es un componente de servidor: no tiene estado ni eventos.

```tsx
import BotonFavorita from "./BotonFavorita";

interface PropsTarjetaAula {
  nombre: string;
  planta: number;
  capacidad: number;
}

export default function TarjetaAula({
  nombre,
  planta,
  capacidad,
}: PropsTarjetaAula) {
  return (
    <article className="rounded-lg border border-zinc-300 bg-white p-4">
      <h2 className="text-xl font-semibold">{nombre}</h2>
      <p>
        Planta {planta} · Capacidad: {capacidad} personas
      </p>
      <BotonFavorita />
    </article>
  );
}
```

1. Sustituye `app/aulas/page.tsx` para que muestre una tarjeta por aula:

```tsx
import TarjetaAula from "../componentes/TarjetaAula";

const aulas = [
  { nombre: "Aula 101", planta: 1, capacidad: 30 },
  { nombre: "Aula 204", planta: 2, capacidad: 24 },
  { nombre: "Taller de informática", planta: 0, capacidad: 20 },
];

export default function PaginaAulas() {
  return (
    <>
      <h1 className="mb-6 text-3xl font-bold">Aulas</h1>
      <ul className="grid gap-4">
        {aulas.map((aula) => (
          <li key={aula.nombre}>
            <TarjetaAula
              nombre={aula.nombre}
              planta={aula.planta}
              capacidad={aula.capacidad}
            />
          </li>
        ))}
      </ul>
    </>
  );
}
```

1. Abre `http://localhost:3000/aulas`. Debe aparecer un **error**. Léelo entero, copia la primera frase en la **Pregunta 2** de la hoja de respuestas y explica con tus palabras qué te dice Next.js que ocurre.
2. Arréglalo añadiendo esta línea al principio de `BotonFavorita.tsx`, y nada más:

```tsx
"use client";
```

1. Recarga `/aulas` y pulsa el botón de varias tarjetas. Cada una se marca y desmarca por separado, sin recargar la página.
2. Con la página `/aulas` abierta pulsa **Ctrl + U** (ver código fuente) y busca «Taller de informática». Aparece en el HTML que llegó del servidor. Anota en la **Pregunta 3** qué te indica eso sobre `TarjetaAula`.
3. Responde la **Pregunta 4**: ahora que `BotonFavorita` es de cliente, ¿por qué `TarjetaAula` no necesita `"use client"`?

**Comprueba:** `/aulas` muestra tres tarjetas y cada botón funciona de forma independiente.
